# UE Swimming & Diving Scheduling and Performance Platform

Senior Computer Science project for the University of Evansville Swimming & Diving team.

## Project Goal

Create a web-based platform that brings team scheduling and swimming
performance information into one system.

The first development priority is helping coaches identify scheduling
conflicts and find practice times that work for the greatest number
of swimmers.

## Users

- UE Swimming & Diving coaching staff
- UE swimmers

## Current Technology

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: relational database planned for later development

## Current Prototype Status

- GitHub repository and project structure created
- React frontend runs locally
- FastAPI backend runs locally
- Frontend and backend communication verified
- `/api/health` endpoint working

## Next Milestone

Build the first scheduling workflow using mock swimmer schedules,
detect conflicts, and begin ranking low-conflict practice windows.
